# linux-fundamentals-cybersecurity
Linux fundamentals practice for cybersecurity engineering including file management, permissions, processes, and networking commands.

## Overview
This project documents my practical learning of Linux fundamentals as part of my cybersecurity engineering journey.

Linux is widely used in cybersecurity for penetration testing, system administration, and security monitoring.

## Objectives
- Understand Linux command line basics
- Practice file management commands
- Learn file permissions and ownership
- Monitor running processes
- Explore networking commands

## Tools Used
- Linux Terminal
- Bash Shell

## Topics Covered

### 1. File Management
Commands practiced:
- ls
- mkdir
- touch
- cp
- mv
- rm

### 2. File Permissions
Commands practiced:
- chmod
- ls -l

### 3. Process Management
Commands practiced:
- ps
- top
- kill

### 4. Networking Commands
Commands practiced:
- ip a
- ping
- netstat
- nslookup

## Skills Gained
- Linux command line navigation
- File system management
- Process monitoring
- Network troubleshooting

## Importance for Cybersecurity
Linux skills are essential for cybersecurity engineers because most security tools and servers run on Linux systems.
